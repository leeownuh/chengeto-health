# Architecture Decision Records

This folder stores short architecture and platform decisions for CHENGETO.

## Naming

Use `ADR-XXXX-short-title.md`, for example:

- `ADR-0001-render-cloudflare-hosting.md`
- `ADR-0002-backend-auth-session-strategy.md`

## Status values

- proposed
- accepted
- superseded
- deprecated

## When to write an ADR

Create an ADR when a decision affects:

- hosting or deployment architecture
- security boundaries
- observability strategy
- data storage or backup approach
- operational cost or reliability tradeoffs
